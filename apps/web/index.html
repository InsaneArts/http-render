Same page, from your terminal.

Copy any request from your browser's network tab as cURL and pipe it in. You get the same file and the same styles, and nothing leaves your machine unless you send it.

~/api
$ pbpaste | npx http-render --open
✓ POST /v1/users/{userId}/orders · 201 Created · 84 ms
  → post-v1-users-userid-orders.html

$ npx http-render https://api.github.com/zen -t graphite
✓ GET /zen · 200 OK · 41 ms → get-zen.html

Document-only renders never leave your browser. Send for real goes through a small relay that only reaches public addresses, stops after 15 seconds and keeps the first 1 MB. Nothing is stored.
